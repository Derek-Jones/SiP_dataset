# Software Development Effort Estimation Dataset

## Description

This dataset contains anonymised software development effort estimation data collected from Software in Partnership Limited for the purpose of supporting research and non-commercial study of software effort estimation, project planning and related software engineering topics.

The dataset includes information such as estimated effort, actual effort, task or project characteristics, development attributes and other variables relevant to software effort estimation.

The dataset has been anonymised prior to release to remove or reduce information that could be used to identify individuals, customers, projects, or other confidential entities.
